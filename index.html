    scSpatial-Kit

    scSpatial-Kit (single-cell Spatial Transcriptomics Kit) is an end-to-end, modular, scalable, and reproducible bioinformatics pipeline designed for sub-cellular resolution spatial transcriptomics. It takes raw vendor data, performs quality control, leverages state-of-the-art deep learning for dimension reduction, infers cell-cell communication, and ultimately packages results for interactive web visualization with Spatial-VisKit.

    Get Started Configuration Guide

    Key Features

    • Supports Major Platforms

      Currently accepts raw datasets from NanoString CosMx and 10x Xenium.

    • Comprehensive Spatial Toolkit

      Uses scVI / scVIVA for spatially-aware deep learning embeddings. Features geometric morphometrics via MuSpAn, neighborhood statistics via Squidpy, causal signaling via LIANA+, and Transcription Factor inference via Decoupler.

    • Automated & Reproducible

      Orchestrated via Snakemake and tracks execution times and logs the exact parameters used for every module, ensuring your spatial analyses are traceable and reproducible.

    • Paired Visualization Tool

      Instantly export your into our web application, Spatial-VisKit, to explore your tissue and analysis results interactively.

    Pipeline Architecture

    scSpatial-Kit is divided into multiple modules. You can run the entire pipeline end-to-end, or only run specific modules.

    1: Pre-Processing & Quality Control

    • Module 0: Format Data — Parses raw datasets into SpatialData format.
    • Module 1: Quality Control — Filters debris/artifacts.
    • Module 1b: Merge Data — Merges multiple batches/slides into one dataset.

    2: Dimensionality & Annotation

    • Module 2: Dimension Reduction — Performs dimension reduction, has many options.
    • Module 3: Cell Annotation — Supports many methods for cell type annotation and finds marker genes.
    • Module 4: Spatial Visualization — Plots annotations and marker genes onto UMAP and physical tissue coordinates.

    3: Spatial & Microenvironment Analytics

    • Module 5: Spatial Statistics — Computes spatial metrics (Neighborhood Enrichment, Co-occurrence, Moran's I).
    • Module 6: MuSpAn — Computes spatial metrics, cell morphometrics (area, perimeter, orientation), and exact physical contact networks.
    • Module 7: TF Enrichment — Infers Transcription Factor activity.

    4: Communication & Differential Expression

    • Module 8: Cell-Cell Communication — Evaluates ligand-receptor crosstalk, signalling niches, and causal intracellular signaling.
    • Module 9: Condition DE Analysis — Performs differential expression analysis between conditions.
    • Module 10: WebVis Export — Packages results for interactive web visualization.
